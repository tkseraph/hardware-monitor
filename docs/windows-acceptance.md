## W5b 原始历史连续段（2026-09-16）

新增数据库版本 2，以可空的 segment_id 扩展原始记录，旧行不回填伪造身份。Windows 每个采集来源带尝试序号；只有连续尝试且上一批数据库事务成功，才沿用连续段。采集失败、空批、队列丢批、数据库写入失败、检测到的时钟异常以及应用重启会使后续记录进入新段。段标记与数值在同一事务写入，数据库未初始化时返回失败，不能确认批次已保存。

新版查询按时间与段标记合并同秒数据，先分段再抽稀。测试覆盖旧 schema 原有行保留、重复打开、同秒不同段不混合、规则的一秒点距仍按段断开，以及未确认写入与重新启动的段隔离。默认 Rust 测试 79 通过、8 忽略；六项显式 Windows 原生采集测试通过；前端 26 项测试及类型检查通过，严格 Clippy 通过。
