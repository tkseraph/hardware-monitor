# Mac 优先验收与验证清单

日期：2026-09-11。状态：依据 D-012 仅调整验收计划，**以下应用测试均未执行，本轮也不执行**。当前验收仅针对 Mac，Windows 条件延后。

依据：[需求决策](requirements.md) · [实施方案](implementation-plan.md) · [能力矩阵](capability-matrix.md)

## 1. 验收环境与证据规则

- Mac：用户本机 M4、macOS 26.5.2、16 GiB，已识别内置/外置两块 SSD。
- Windows：HX 370 / Radeon 890M、Win11 Pro 25H2 资料只作后续参考；当前不探测、不测试、不要求准备该设备。
- Mac 分别记录普通权限、增强组件未授权/启用/停用的条件；Windows 驱动条件移至后续验收。
- 每份结果包含应用/来源/依赖版本、系统环境、实际步骤、样本和时间窗口、预期与实际、通过/失败/阻塞。
- 编译通过、模拟夹具通过、静态设备识别与实机动态验收是不同证据；不能相互替代。
- 不自动提权、修改安全设置、发起长时间满载或磁盘压力写入；必要的可控负载须说明范围后执行。
- 文档允许的指标降级不能用于规避 D-010 基础目标；基础项无法采集需列为阻塞并请用户确认变更。

## 2. 产品验收清单

下表是当前 Mac 交付的验收范围，状态均为“未执行”。需在后续获准开发时实施，不以本次文档调整宣称通过。Windows 结果不是这些项目的通过前提。

| ID | 验证场景 | 通过条件 |
| --- | --- | --- |
| V-01 | Mac 安装运行 | 本机通过 app/DMG 正常安装启动，不依赖开发命令、Node/Rust SDK 或手工启动采集命令 |
| V-02 | 总览与四类详情 | CPU/GPU/内存/磁盘核心状态同页可见；可进入对应详情；在已验证的权限条件下四类均有真实动态数据 |
| V-03 | CPU 差分与核心 | 首次采样预热；总/每逻辑处理器占用在同口径时间窗合理变化；分组有实机映射依据，不按猜测划分 |
| V-04 | GPU 利用率 | 本机其他程序的 GPU 活动能反映到全局指标；Mac 来源方法与聚合可解释，不把进程自身或无依据引擎加总当整机值 |
| V-05 | GPU 内存 | 区分专用/预留/共享/统一内存及预算；不是监控进程自身用量；没有正确分母时不生成虚假百分比 |
| V-06 | 系统/进程内存 | 安装量、系统可用总量、当前用量/可用/空闲不混淆；进程表有排序搜索；共享页不无条件重复累计成整机用量 |
| V-07 | 多盘与卷 | 本机两块 SSD 分别展示；物理盘/容器/卷关系可解释，APFS 共享空间不重复累计，不按卷名猜物理归属 |
| V-08 | 磁盘性能与容量 | MB/s、活动时间%与容量占比不同名；读写差分与实际窗口一致；不把卷重复计数当物理吞吐 |
| V-09 | 进程存储读写 | 排行明确系统范围，不宣称属于当前盘；实际来源确为标注的 I/O 类型；网络 I/O 不冒充纯磁盘吞吐 |
| V-10 | 状态真实性 | 0、预热、未实现、未验证、不支持、不适用、无权限、失败、过期可区分；生产模式无模拟数据 fallback |
| V-11 | 前后台采样 | 前台/后台主要动态指标目标 1 秒/3 秒，可配置；按实际采样时间写历史；隐藏后停止无用动画，不重复启动来源 |
| V-12 | 7 天本地历史 | 重启可查保留期数据；较老数据按规则聚合；设备级记录本地保存，进程明细默认不落盘；无自动上传 |
| V-13 | 缺口与时间变化 | 停采/睡眠/故障保持缺口；系统时间跳变、计数重置、PID 重用不产生伪峰值；新样本不伪装覆盖整段空白 |
| V-14 | 关窗/退出/自启 | 关窗后 Mac 菜单栏可恢复，历史继续；明确退出后停止本应用采集；自启默认关闭，启用/关闭均可验证 |
| V-15 | 睡眠与唤醒 | 无防睡眠断言或主动唤醒；唤醒恢复适当来源、重建差分基线；历史保留睡眠缺口 |
| V-16 | 授权与安全 | 拒绝 Mac 增强授权时基础功能继续；不关闭 SIP 等保护；XPC 调用者身份可验证；组件接口不能执行任意命令、读写任意路径或控制硬件 |
| V-17 | 优先增强 | 可读温度/通电/健康来自已验证来源；thermal pressure 不当温度、Verified 不当磨损%；风扇无读数不当 0 RPM |
| V-18 | 故障恢复 | 来源超时、解析失败、组件崩溃/失联、设备移除均有明确状态；单一来源失败不冻结全应用；没有僵尸采集任务 |
| V-19 | 历史存储故障 | 磁盘满、数据库忙/损坏/迁移失败有可见错误；不静默删历史；基本实时查看可独立运行 |
| V-20 | 卸载与停用 | 可撤回 Mac 增强授权和停用采集；正常退出/异常退出任务回收；卸载自身 helper/注册项，不破坏其他软件组件 |
| V-21 | 自身资源与隐私 | 提供全进程树 CPU/内存/历史容量和后台运行报告；说明未达到的工程目标；诊断默认脱敏且不自动上传 |

## 3. 分层测试

### 单元与属性测试

- CPU 时间差分、实际间隔归一、零间隔、计数回退/溢出、首样本、源重启。
- 字节/容量/温度/传输速率单位；JavaScript 安全整数边界和 DTO 往返。
- 物理盘/卷/存储池多对多关系、共享空间、身份变化、未知归属。
- PID 重用、进程退出、访问被拒绝、同名不同程序、共享内存重复计数。
- 能力状态与样本状态组合、来源代次变化、旧值过期、策略切换。
- 时间加权聚合、极值、有效覆盖率、稀疏样本、保留期边界和不伪造缺口。

### 解析与集成测试

- 使用脱敏的真实来源输出夹具；模拟夹具只能进入测试/显式开发环境。
- powermetrics plist 流可能含 NUL 分隔，多条/半条数据、字段缺失、单位变化和工具异常要单独测试。
- Mac 来源返回字段变化、P/E 核映射、进程身份、IOKit 设备变化与 APFS 拓扑解析。
- SQLite schema 迁移、写入中断、WAL/checkpoint、过期清理、数据库锁定和恢复路径。
- 前后端契约、IPC 参数校验、来源订阅去重、取消采集和超时回收。
- 使用可控时钟验证 7 天保留规则；另做真实后台稳定性测试。加速时间测试不等于已运行 7 天。

### UI 与平台实测

- 核对核心文字、单位、状态、无数据说明、导航和可访问性；数值更新不使页面跳动或丢失排序操作。
- 覆盖浅/深色、常见桌面窗口尺寸、小窗口、多个设备/大量进程、长名称。
- Web 预览只验证界面，不验证 Mac 菜单栏、权限、安装或系统采集；这些必须在本机打包应用中检查。
- 对照系统工具时匹配统计来源/口径/窗口，保留差异解释，不能要求不同算法每个瞬间数值完全相同。
- GPU 用量验证必须用监控进程以外的实际活动；磁盘测试区分进程逻辑 I/O、缓存和物理盘吞吐。

## 4. 资源与长期运行方法

工程建议而非已承诺达标的 SLO：

1. 基础/增强模式分别记录至少 10 分钟稳定空闲窗口的 CPU、内存、磁盘写入和样本延迟。
2. 统计主程序、WebView、所有子进程与增强组件；CPU 按整机逻辑计算容量归一，并标明内存指标与共享页计算方式。
3. 前台持续切换图表、排序进程、查询 7 天历史；后台隐藏后对比资源，确认不持续渲染。
4. 首版发布前安排至少一次两小时稳定运行，以及可行的更长后台观察；记录资源趋势而非只截取最低瞬时值。
5. 记录来源耗时 P50/P95、漏采/过期次数、队列上界、历史存储增长；超出建议预算先定位来源，不悄悄改变已确认行为。
6. 完全退出检查组件是否停止采集；控制进程异常退出检查租约回收。仅看窗口消失不算退出验证通过。

## 5. 停止与升级报告条件

遇到以下情况应暂停对应实现路径，提供证据与替代方案，而不是自动越过约束：

- 四类基础目标之一没有真实数据来源，或只能得到错误统计范围的数据。
- 必须关闭系统安全保护、使用已知有未修复漏洞的驱动、或无法验证调用者身份。
- 需要购买账号、证书、云服务，上传源码/报告或对外发布。
- 温度/健康只能通过推测得到，或某数据来源无法在睡眠/退出后被可靠停止。
- 历史保留、采样、权限或进程隐私必须偏离已确认决策才能达到资源目标。

## 7. Mac 完成与 Windows 扩展门槛

- Mac 已确认的总览/详情、真实采集、进程、历史、菜单栏、权限、睡眠恢复、稳定性与安装验收全部有结果，不能以 M1 原型代替完整交付。
- 原始指标清单逐项列明完成、已验证不可用、未实现/未验证或后续迭代状态；基础验收偏差未处理时不得宣布“Mac 全部跑通”。高级指标仍遵循 D-010 分阶段安排，不在本次悄悄删减。
- Mac 整体验收通过、限制与剩余项已列明后，由用户后续明确决定是否开始 Windows；当前不自动启动任何 Windows 任务。

Windows 专用条件只保留为后续清单：Windows 安装/WebView2、GPU 引擎/内存口径、计数器本地化、进程纯存储 I/O、盘卷映射、托盘/自启、服务/管道 ACL、驱动独立授权与安全设置、共享驱动卸载保护及 Windows 资源实测。届时必须用 Windows 实机验收，Mac 通过不作替代。
