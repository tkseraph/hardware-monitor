# Windows 进程磁盘 I/O 接入（2026-09-30）

## 已实现的产品行为

进程页提供“启用磁盘采集”“停止磁盘采集”和“单次验证（采集 20 秒自动停止）”。默认关闭；只有用户主动启用时请求 UAC，主界面保持普通权限。常规启用后关闭窗口到托盘继续采集，停止或退出软件后结束自身会话。单次验证的 20 秒预算从 StartTrace 成功时开始，由采集循环执行，不依赖界面操作速度；清理与组件退出可能随后完成。

CPU 温度、磁盘增强与进程磁盘事件使用各自的入口，启用其中一项不会启动其他高权限来源。新进程磁盘组件不安装驱动、注册服务、读取文件路径或写入 ETL/进程明细历史。

## 指标口径与质量

- 速率来自 ETW 磁盘发起/完成事件，以实际完成事件窗口字节数除以窗口时长。缓存命中的逻辑文件读取可能不产生磁盘事件，因此不能作为程序全部文件 I/O 或网络/设备 I/O 的总量。
- 归属只采用持有的原生线程/进程身份、进程创建 FILETIME 和事件时间范围，完成事件的头部 PID 不用于猜测归属。范围始终是核验过的部分进程，不能宣称全系统覆盖。
- 页面区分关闭、待授权、预热、有效、不完整、过期、停止中和失败。有效窗口也只为覆盖完整窗口且创建时间匹配的进程显示速率；不可读、新建或已退出的实例保留未知值。
- 有无法归属、丢失、拒绝或过期操作的窗口不发布数值；其后干净的窗口可恢复。事件丢失、顺序或时钟故障使源退出，须重新启用。未知值和失效值显示“—”，不补成 0。
- 全局质量包含当前窗口未归属次数/字节数、丢失/拒绝/过期次数；身份核验详情是本次启用的累计计数，细分句柄或身份读取失败、事件时间生命周期未确认、时钟换算失败与容量限制。计数不等于系统覆盖率，也不把所有失败都解释成权限不足。
- 后端相同快照被重复读取时不更新其新鲜度，接收后超过 5 秒撤销速率。界面也根据页面响应年龄隐藏过期数据；读取进程页失败同样隐藏速率。
- Windows 不提供进程启动以来累计磁盘计数，兼容字段 `disk_read_bytes`/`disk_write_bytes` 保留未使用的占位值；界面只展示上述速率。macOS 原有累计计数来源不变。

## 有界传输与退出

独立命名管道复用已实现的 OS 对端 PID、进程创建时间、SID、登录会话和链接 UAC 令牌核验。握手使用固定版本与随机 nonce；命令只包括握手、读取和停止，不接受文件、脚本、DLL 或设备控制参数。请求序列不可重放。

一次最多 4096 个 `(PID, creation FILETIME)` 记录，每帧最多 128 行，沿用 64 KiB 帧上限。分段必须具有相同会话、快照序列、元数据与连续偏移，收齐并核验重复身份、速率、窗口、状态后一次替换缓存。整个快照的接收预算为 4 秒；不会先展示半份数据。普通进程完整扫描与身份合并发生在过滤、排序、分页之前。

原生回调只解码并投递到 8192 容量队列，身份查询和聚合在消费线程完成。采集组件仅保存最新快照；父进程每秒读取、页面每两秒刷新。组件命令等待超过 10 秒或断连时取消采集，执行 StopTrace、CloseTrace 并等待消费者退出。主进程停止时立即撤销缓存；同时核对停止答复、持有的组件进程句柄和成功退出码，清理无法确认时阻止本次应用运行再开第二个源。

采集组件自身被强制终止时的 ETW 残留识别/回收尚未完成，不能把正常退出代码路径视作崩溃清理保证。正式组件的受保护安装位置、签名和升级卸载仍由 E5/W7 收尾；当前是开发目录构建。
