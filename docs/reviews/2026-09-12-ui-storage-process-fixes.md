# UI、存储容量与进程终止修正

- 修复语言选择器、采集状态标签、导航默认/悬停/选中的深浅色前景与背景配对。
- 本机只读探测确认 APFS 容器有 CapacityCeiling / CapacityFree，没有 CapacityInUse；前端补齐已用 = 上限 − 剩余。未知/异常/重复容器不产生伪读数。
- 存储行展示物理总容量、APFS 已用量、占用率和分母口径；保留温度与历史。
- 结束进程遵循 D-013，只发送 SIGTERM；确认面板默认聚焦取消，发送中禁用按钮，防止重复提交。权限不足不尝试提权。

## 验证

- Node 4 项容量测试：差值、直接读数、多容器、真实零、缺失/越界/重复等。
- Rust 子进程测试：保护 PID、错误启动时间不发送信号、专用 sleep 子进程收到 SIGTERM；未终止用户应用。
- 浏览器：实际计算样式已核对深浅色前景/背景，语言切换正常，控制台无错误。
- 临时验证页使用允许字段的真实磁盘容量快照验证两盘读数与窄屏无横向溢出；温度未读取，显示缺值。进程交互使用显式标识的 UI 测试夹具（不会发送系统信号），验证选中、二次确认、请求已发送、权限不足反馈。验证页和快照均已删除，不发布。
- 浏览器交互与原生 SIGTERM 分别验证；尚未声称在打包应用里完成端到端点击终止测试。
