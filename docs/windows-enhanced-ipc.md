# E1 增强采集通信基础（2026-09-23）

本阶段实现普通权限进程间通信基础，未接入真实 ETW/温度/健康读取，未启动管理员组件，未注册服务或安装驱动，未修改桌面快捷方式。范围依据 [首版增强指标方案](plans/2026-09-21-windows-enhanced-v1-scope.md)。

## 实现

- `src-tauri/src/enhanced/protocol.rs`：长度前缀 JSON、固定版本、严格字段白名单、单调请求序号。只接受 Hello、Sample、Heartbeat、Shutdown；没有任意命令、路径或插件接口。
- `src-tauri/src/enhanced/pipe.rs`：仅本机会话命名管道、随机名称、first-instance、防远程连接、单客户端，输入/输出管道缓冲各 8 KiB。显式 DACL 只授权创建用户；同时验证实际对端 PID、持有进程句柄的创建时间、用户 SID、Windows session 和 token AuthenticationId。客户端默认使用 identification 级别 QoS，避免向管道服务器授予模拟权限。
- 双向身份验证使用系统返回的管道进程信息，不接受消息中自报身份。持有的进程句柄用于抵御 PID 复用；对端已退出、身份变化、不同用户或登录身份均拒绝。
- 32 位长度前缀在分配消息缓冲前检查，单帧最多 64 KiB，快照最多 256 行。温度和速度检查有限数值、身份字段限定格式，进程创建标记使用十进制字符串，快照包含毫秒观察时间。
- 握手和后续请求空闲期限各 5 秒，写入期限 2 秒，异步来源响应期限 2 秒，取样请求最小间隔 200 ms。每连接一次只处理一个请求，没有无限消息队列。坏帧、错误版本、重复序号、未知命令/字段、断线和超时都结束相应会话。
- `examples/enhanced_ipc_check.rs`：显式开发验收程序，启动自身的普通权限测试子进程，用标准输入传递握手随机值；核验真实管道通信、Heartbeat、NotImplemented 响应、Shutdown 与子进程退出。错误路径只回收自己启动的子进程，不使用模拟硬件指标。

主界面未调用本模块，也没有向 SQLite 写入测试值。温度 42°C 等合成数据只编译在 Rust 单元测试中。示例返回“未实现”，不伪装成传感器读数。

## 验证结果

2026-09-23：默认 Rust 92 通过、0 失败、8 个硬件/操作测试忽略；严格 Clippy 与格式检查通过。新增 8 项测试覆盖：过大/截断/未知帧、错误 nonce、版本、未知字段、重复序号、断线、来源停滞、慢读者、空闲超时、无效值/行数、管道实例隔离及身份不匹配。

第一次严格字段测试发现 serde 的无参数枚举变体会接受额外字段，已改为显式空结构变体并通过回归。不是仅在测试中忽略多余字段。

实际运行验收示例通过：一个独立普通权限子进程与父进程完成双向身份验证、握手、心跳、未实现来源响应、正常退出。运行命令：

```powershell
cargo test --locked --manifest-path monitor-app/src-tauri/Cargo.toml
cargo clippy --locked --manifest-path monitor-app/src-tauri/Cargo.toml --all-targets -- -D warnings
cargo run --locked --manifest-path monitor-app/src-tauri/Cargo.toml --example enhanced_ipc_check
```

## E2 前仍需完成的工作

这不是已经可部署的高权限组件。真实提升权限后的 split-token/登录身份兼容性、安装目录防篡改、二进制及依赖信任、授权启动/取消流程需在 E2 具体实现后验证。身份检查失败必须继续拒绝，不能为了通过测试降级为只校验 PID 或随机名称。本文的错误身份测试包含构造不匹配期望值；不同 Windows 账户/远程机器的实际连接测试尚未执行。

未来管道接收方必须先调用对端验证，再进入协议状态机，并校验回复版本、序号和快照。传感器原生阻塞调用不能直接放进当前异步来源回调：超时只能取消可协作异步等待，不能假称已终止任意阻塞驱动调用。E2 要为这类调用补齐专用线程/子进程的有界退出策略。

256 行是当前协议保护上限，不是允许只取前 256 个进程。完整进程排行接入前需设计受总量约束的分块/分页快照和完整性语义，超过上限应拒绝或显示不完整，不能静默截断。真实磨损、通电、事件丢失计数和完整字段语义将在真实来源确认后扩展版本化协议。

本轮只验证正常身份的真实父子进程及正常退出；UI 崩溃后的实际子进程树回收、ETW 残留会话清理、管理员令牌与驱动卸载不在此次通过范围。原有桌面版本、先前原生窗口和睡眠验收结论不能自动扩大为 E1/E2 全部验收。
