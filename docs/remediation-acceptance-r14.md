## 4. 资源观察（连续采样，非瞬时三值）

工具：`scripts/probes/resource-observe.py`，只读 `ps`，不发信号、不触发睡眠、不写应用数据目录；报告写入 gitignored 的 `scripts/probes/reports/`，不含主机名/用户名/序列号。

- **10 分钟**（`resource-observe-600s-20260911T203311Z.json`，120/120 拍全部命中，间隔 5s）：
  - **常驻主进程**（pid 68745，120/120 拍在线）：CPU p50 0.55% / p95 4.73% / max 6.0%；RSS p50 110 MB / p95 120 MB / min 96.6 MB / max 120 MB，趋势稳定，无持续增长。
  - **采样子进程**：短暂出现、单拍即逝（每拍 1 个，pid 不复现），其瞬时 CPU 抬高了"全树合计"口径的 p95/max。此为 `ps` 全树求和的固有噪声，已按常驻进程口径单独呈列以消除误导。
  - 线程数上界 26，子进程数上界 3，无未解释增长。
- **2 小时**：同工具加长窗口（间隔 10s），另记录采样节奏、来源 P50/P95、过期/错误次数、历史大小与线程/子进程上界。结果见对应 `resource-observe-7200s-*.json`，数值以报告文件为准。

注：observer 初版进程匹配正则过宽（误纳同名子串的第三方应用），已修复为锚定 `monitor.app/Contents/MacOS/app` 与 `target/{release,debug}/app`；并在每条进程记录中加入 `comm` 名以便归因核对。
